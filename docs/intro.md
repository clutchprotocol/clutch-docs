# Introduction

Welcome to **Clutch Protocol** developer documentation. Clutch Protocol is a decentralized ride-sharing blockchain that cuts platform fees from 15–25% to 5–8%, enables instant payouts, and empowers users through community governance.

## Architecture

Clutch Protocol consists of:

| Component | Description |
|-----------|-------------|
| **Clutch Node** | Blockchain core with Aura consensus, custom transaction format |
| **Clutch Hub API** | Application-to-node bridge (GraphQL, REST) |
| **Clutch Hub SDK (JS)** | Transaction signing, encoding, blockchain interaction |
| **Clutch Deploy** | Full-stack Docker Compose deployment |

## Key Features

- **Ultra-low fees** — 5–8% vs 15–25% on traditional platforms
- **Instant payouts** — Drivers receive payments immediately
- **Transparent & secure** — On-chain transactions, client-side signing
- **Developer-friendly** — SDKs, GraphQL API, Docker deployment
